## Project Context

This project is a salon CRM built with Python and HTML. When modifying backend logic, check for corresponding changes needed in HTML templates and vice versa.

## File Editing

When working with files the user claims to have saved or edited manually, always verify the file contents with `Read` before proceeding. Do not assume manual saves were successful.

## Verification

After completing multi-file changes, run the application or relevant tests to verify everything works end-to-end before reporting completion.
